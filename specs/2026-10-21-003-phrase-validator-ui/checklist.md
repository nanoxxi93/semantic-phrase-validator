# Lista de Comprobación y QA: 003-phrase-validator-ui

## Entornos de Prueba Requeridos
- [x] Navegador Web moderno (Google Chrome, Firefox o Edge en sus versiones recientes) con soporte para ES2022+ y Fetch API.
- [x] Entorno de Servidor Backend local en Node.js 24 (`npm --prefix backend run dev`) escuchando en `http://localhost:3000`.
- [x] Entorno de Desarrollo Frontend con Vite (`npm --prefix frontend run dev`) en `http://localhost:5173`.
- [x] Entorno CLI de pruebas automatizadas con Vitest y `@vue/test-utils` (`npm --prefix frontend run test`).
